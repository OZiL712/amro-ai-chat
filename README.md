# Amro AI CHAT ✨

تطبيق محادثة ذكاء اصطناعي عربي متطور وفائق السرعة، مبني باستخدام **Python (Flask)** وواجهة برمجة تطبيقات **Google Gemini API** مع دعم البث المباشر للإجابات (Streaming SSE) ودفتر ملاحظات متقدم لحفظ وتنظيم وإدارة المحادثات.

---

## 👨‍💻 المطور
* **الاسم:** عمرو الشرافي (Amro Alshurafy)
* **المسمى:** مهندس برمجيات ومطور تطبيقات وويب وذكاء اصطناعي (Flutter • React • Python • AI Solutions).
* **التعليم:** طالب تقنية معلومات (IT) — جامعة شبوة.
* **معرض الأعمال والسيرة الذاتية:** [amrocv.vercel.app](https://amrocv.vercel.app)

---

## ✨ المميزات الرئيسية

1. **⚡ بث مباشر حي للإجابات (Streaming SSE):**
   * استقبال الإجابات وطباعتها كلمة بكلمة في الوقت الفعلي مع مؤشر كتابة نابض وزر للإيقاف الفوري `⏹️`.
2. **🧠 إدارة متقدمة لنماذج الذكاء الاصطناعي:**
   * استخدام أحدث نماذج Google Gemini مع آلية تحويل مسار تلقائية ذكية (Automatic Seamless Failover) تضمن استمرارية الخدمة.
3. **🛡️ أمان وحماية عالية:**
   * محدد معدل الطلبات في الذاكرة (Thread-safe Rate Limiter) لمنع إغراق الخادم واستنزاف الحصة.
   * حماية كاملة لمفتاح الـ API وعدم تصديره أو تسريبه للواجهة الأمامية.
   * تطهير المدخلات والمخرجات لحماية المستخدم من هجمات XSS وحقن الأكواد الضارة عبر `DOMPurify`.
4. **📒 دفتر ملاحظات متطور وتفاعلي:**
   * حفظ المحادثات تلقائياً محلياً في المتصفح.
   * شريط بحث فوري للوصول لأي محادثة سابقة.
   * إمكانية تثبيت المحادثات المهمة في الأعلى (`📌`).
   * إمكانية إعادة تسمية أي محادثة (`✏️`).
   * إمكانية تصدير المحادثة كملف `Markdown (.md)` أو `نصي (.txt)` أو طباعتها.
5. **🎨 واجهة مستخدم عصرية ومتجاوبة (UI/UX):**
   * دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL) بخط Cairo.
   * متجاوبة 100% مع الهواتف الذكية والشاشات اللوحية والحواسيب.
   * دعم كامل لتنسيق Markdown والجداول، وتلوين كتل الأكواد البرمجية لجميع اللغات (Syntax Highlighting عبر `Highlight.js`) مع زر نسخ مخصص لكل كود.
   * دعم نطق الإجابات صوتياً (Text-to-Speech).

## 🚀 طريقة التثبيت والتشغيل محلياً

1. **استنساخ المستودع:**
   ```bash
   git clone <REPO_URL>
   cd amro-ai-chat
   ```

2. **تثبيت الحزم المطلوبة:**
   ```bash
   pip install -r requirements.txt
   ```

3. **إعداد مفتاح Gemini API:**
   أنشئ ملف `.env` وضع فيه مفتاحك:
   ```env
   GEMINI_API_KEY=your_actual_gemini_api_key_here
   PORT=7860
   ```

4. **تشغيل التطبيق:**
   ```bash
   python app.py
   ```
   افتح المتصفح على: `http://localhost:7860`
